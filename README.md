# Órbita — Compliance na Era Digital

Apresentação web com 64 slides, navegação por setas, biblioteca de vídeos e reprodução de MP4/GIF no navegador.

## Hospedagem
O site é estático: abra `index.html` pelo GitHub Pages. Os arquivos originais estão em `slides/` e `videos/`, sem dependência de permissões do Google Drive.

Slides com mídia associada: 36, 37, 43, 45, 47, 49, 50 e 53. O menu Biblioteca de vídeos mostra os dez arquivos disponíveis, inclusive vídeos auxiliares sem slide específico.

**Nota:** Slides 46, 51, 54–57 têm referências/áreas de demonstração sem arquivo correspondente confirmado na pasta fornecida. Não foi inventado vídeo para esses casos.
